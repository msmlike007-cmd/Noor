# নূরনামা — রিলিজ চেকলিস্ট

## এই প্যাকেজে সম্পন্ন
- আপলোড করা Dart ফাইলগুলো `lib/`-এ সাজানো হয়েছে।
- More মেনুতে `হাদিস` পাঠাগার সূচি যুক্ত হয়েছে; এতে সহিহ বুখারি, সহিহ মুসলিম, সুনান আবু দাউদ, তিরমিজি, নাসাঈ, ইবন মাজাহ, মুয়াত্তা ও নওয়াবীর ৪০ হাদিসের অনলাইন উৎস-লিংক আছে।
- ভার্সন 2.1.1+4 করা হয়েছে।
- সংরক্ষিত থিম/হিজরি সমন্বয়/আরবি ফন্ট সাইজের মান সীমার মধ্যে আনা হয়েছে।
- Codemagic AAB workflow এবং Android SDK 36 কনফিগারেশন যোগ করা হয়েছে।

## এখনো বাকি / গুরুত্বপূর্ণ সীমাবদ্ধতা
1. হাদিস পেজটি অনলাইন গ্রন্থে লিংক করে। পূর্ণ বাংলা হাদিস ডেটাবেস বা offline hadith cache এখনো নেই।
2. Sunnah.com API-তে API key চাইতে হয়; তাদের সব ডেটা API-তে নেই এবং offline dump বর্তমানে সাধারণভাবে পাওয়া যায় না। তাদের শর্ত অনুযায়ী অনুমতি ছাড়া scraping বা বই/collection-এর ব্যাপক পুনঃপ্রকাশ করা যাবে না।
3. HadithBD স্পষ্টভাবে লিখিত অনুমতি ছাড়া তাদের ডিজিটাল ডেটা ব্যাপকভাবে কপি/স্ক্র্যাপ/অ্যাপে প্রকাশ নিষিদ্ধ করেছে। তাই তাদের কনটেন্ট কপি করা হয়নি; কেবল ওয়েবসাইট লিংক আছে।
4. কুরআনের মূল সূরা পৃষ্ঠায় বাংলা উচ্চারণের পূর্ণ ডেটা এখনো নেই। কয়েকটি দোয়ার জন্য আলাদা উচ্চারণ আছে, কিন্তু তা পুরো কুরআনের জন্য নয়। যাচাইকৃত বাংলা উচ্চারণ-ডেটা ও পুনর্বিতরণের অনুমতি ছাড়া বানিয়ে যোগ করা হবে না।
5. আজানের অডিও বাদ। বর্তমানে ফোনের alarm sound ব্যবহার করার fallback আছে।
6. Privacy Policy-র খসড়া অ্যাপের চূড়ান্ত আচরণ ও ব্যবহৃত SDK দেখে সংশোধন করতে হবে। GPS coordinate Nominatim-এ reverse-geocoding-এর জন্য পাঠানো হয়; Data safety-তে যথাযথভাবে জানাতে হবে।
7. Codemagic-এ `nurnama_keystore` signing reference সেট করতে হবে। Signing key নিরাপদে ব্যাকআপ রাখুন।
8. AAB build-এর পরে Android ফোনে নামাজের সময়, লোকেশন অনুমতি, কিবলা, নোটিফিকেশন, offline Quran cache, theme এবং সব screen পরীক্ষা করুন।
9. Play Console-এ Privacy Policy URL, Data safety, content rating, target audience, screenshots, 512×512 icon এবং 1024×500 feature graphic পূরণ করতে হবে।
10. নতুন ব্যক্তিগত Play Console account হলে প্রযোজ্য closed-testing শর্ত account owner-কে পূরণ করতে হবে।

## যাচাইয়ের অবস্থা
- `setup.py` Python syntax: পরীক্ষা করা হয়েছে।
- Flutter/Dart analyze ও Android build: এই পরিবেশে SDK না থাকায় চালানো যায়নি।
- তাই এই প্যাকেজকে build-ready configuration বলা যায়, Play Store-approved বা fully tested build বলা যায় না।
